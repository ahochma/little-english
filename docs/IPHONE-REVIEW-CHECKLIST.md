# iPhone caregiver review checklist — fire-truck prototype

Use this after opening the local private preview in Safari. This is a product review, not an iOS build verification.

## The child session
- [ ] The Hebrew parent screen is clear before the child begins.
- [ ] A child can start with one obvious tap.
- [ ] The child understands the picture-first activity without needing to read.
- [ ] The four words feel appropriate: fire truck, red, ladder, wheel.
- [ ] Tapping a picture/replay feels simple and satisfying.
- [ ] A wrong choice feels calm and encourages another try.
- [ ] Buttons are easy to hit on the iPhone.
- [ ] The complete session feels comfortably below seven minutes.
- [ ] Stop returns to a calm resting screen.

## Audio
- [ ] Safari produces an understandable US-English voice after tapping Start.
- [ ] The speed feels suitable for a toddler.
- [ ] If there is no voice, the Hebrew notice is understandable and the lesson stays usable.
- [ ] Decide whether the future native app should use a warm child-friendly female voice, male voice, or both for parent selection. Default recommendation: one consistent warm US-English voice, without a child-facing voice selector.

## Decisions to send back
1. Keep or replace any of the four first words?
2. Is the visual style (friendly, simple illustrated fire truck) right for your child?
3. Is the voice acceptable, or should native use a specifically produced/bundled voice asset?
4. Which device will be the first native test target: iPhone, iPad, or both? Include the iOS version if available.

## What happens after approval
The next milestone is a small offline native SwiftUI lesson with XCTest. It remains private: no App Store work, accounts, tracking, ads, purchases, or child data collection.
